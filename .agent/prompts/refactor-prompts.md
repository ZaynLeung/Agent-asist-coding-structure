# 重构相关提示词

## 行为不变重构

```text
请对目标模块做行为不变重构，要求：
1) 保持对外接口与运行行为不变
2) 优先提升可读性与可测试性
3) 提供重构前后关键差异点
4) 给出验证步骤与可能的回滚方式
```

## 性能优化

```text
请对该路径进行性能优化，要求：
- 先标注疑似瓶颈点与原因
- 说明测量方式（profiling/指标/日志）
- 给出 2 种方案：低风险与高收益（含取舍）
- 提供验证与回归测试建议
```

## 解耦与模块化

```text
请提出解耦方案：
- 识别耦合点（数据/控制/时间）
- 给出新的模块边界与依赖方向
- 定义接口与数据契约
- 说明迁移步骤（分阶段）与兼容策略
```
