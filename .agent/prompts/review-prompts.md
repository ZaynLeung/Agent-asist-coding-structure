# 代码审查相关提示词

## 通用审查

```text
请对该变更进行代码审查，覆盖：
1) 正确性（边界条件、空值、异常）
2) 可维护性（命名、结构、重复、依赖）
3) 性能（热点路径、I/O、缓存、复杂度）
4) 安全性（注入、鉴权、敏感信息、权限）
5) 可测试性（单测可写性、回归点）
输出格式：
- 必改项（含原因与建议）
- 可选优化（含收益与风险）
- 建议的验证步骤
```

## 安全专项

```text
请做安全专项审查，重点关注：
- 输入校验与注入风险（SQL/命令/路径/模板）
- 权限与鉴权绕过
- 敏感信息泄露（日志、错误信息、配置）
- 依赖风险（供应链、版本、已知漏洞）
仅输出风险点与修复建议，不输出无关总结。
```
