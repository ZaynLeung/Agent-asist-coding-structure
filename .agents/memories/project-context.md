# 项目背景与上下文

## 背景

本仓库用于沉淀 Codex 智能助手在工程项目中的标准化“协作层”：规则、提示词、模板、任务看板与项目记忆。同时作为**机器人学相关知识库**的承载仓库，覆盖机器人学、灵巧手、移动与操作模型、强化学习、持续学习、自迭代与部署后学习。

目标是让多轮对话的产出可复用、可审计、可持续演进，并使领域知识可版本化、可检索。

## 核心概念

- 规则（Rules）：对行为、风格、安全与交付质量的约束
- 提示词（Prompts）：高频场景下的结构化输入模板
- 模板（Templates）：可直接复用的交付格式（需求/缺陷/变更）
- 任务（Tasks）：基于看板的进度管理
- 记忆（Memory）：ADR、踩坑与阶段目标沉淀
- 知识库（Knowledge）：领域主题笔记、资源与术语

## 当前阶段目标

- 建立知识库框架与导航
- 逐步填充核心主题内容（优先：强化学习 → 持续学习/自迭代 → 灵巧手 → 移动操作）
- 保持可追溯的决策与任务管理
