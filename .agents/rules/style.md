# Style Rules

## 命名

- 类/类型：UpperCamelCase
- 函数/方法/变量：lowerCamelCase（以语言社区主流为准）
- 常量：UPPER_SNAKE_CASE
- 文档文件：kebab-case 优先

## 文档与结构化输出

- 优先使用标题 + 列表的结构，避免大段散文
- 结论应可执行：附带命令/步骤/路径
- 重要信息可追溯：给出明确文件路径或链接

## 变更纪律

- 最小 Diff：避免无关格式化与大规模重排
- 分层修改：先重构结构再改行为，或反之，但不混在一次变更里

## 安全

- 不写入或输出密钥/Token/私钥/个人隐私
- 对外部输入做校验，避免路径穿越与命令注入
