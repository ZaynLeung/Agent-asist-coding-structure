# SKILL: code-review

## 目标

对 MR/PR/commit/分支差异进行结构化审查，覆盖正确性、可维护性、性能与安全性，并给出可执行建议与验证步骤。

## 适用场景

- 新功能合入前质量把关
- 缺陷修复后的回归与风险扫描
- 重构后的行为一致性检查

## 输入要求

- 变更范围：文件列表或差异内容
- 运行环境与关键约束（如 OS、CPU/NPU、版本）
- 风险偏好：保守/激进

## 输出格式

- 必改项：问题、影响、建议修改方式
- 可选优化：收益、风险、替代方案
- 验证清单：建议的测试/命令/回归点

## 审查清单

### 正确性

- 空值/越界/异常分支是否覆盖
- 状态机/并发/重试逻辑是否存在竞态
- 输入输出契约是否清晰、是否破坏兼容

### 安全性

- 是否存在注入风险（路径/命令/模板/SQL）
- 是否泄露敏感信息（日志/错误信息/配置）
- 权限边界是否清晰（读写范围、最小权限）

### 可维护性

- 命名是否表达意图、模块边界是否合理
- 是否引入重复逻辑、是否可以抽象复用
- 是否增加测试与文档以支撑长期维护

### 性能

- 热点路径是否有不必要的 I/O、拷贝与序列化
- 是否存在可缓存结果与批处理机会
