# 项目背景与上下文

## 背景

本仓库用于沉淀 Codex 智能助手在工程项目中的标准化“协作层”：规则、提示词、模板、任务看板与项目记忆。目标是让多轮对话的产出可复用、可审计、可持续演进。

## 核心概念

- 规则（Rules）：对行为、风格、安全与交付质量的约束
- 提示词（Prompts）：高频场景下的结构化输入模板
- 模板（Templates）：可直接复用的交付格式（需求/缺陷/变更）
- 任务（Tasks）：基于看板的进度管理
- 记忆（Memory）：ADR、踩坑与阶段目标沉淀

## 当前阶段目标

- 建立可用的最小骨架（MVP）
- 形成可复用的提示词与模板库
- 让关键决策与经验在仓库内可检索与可回溯
