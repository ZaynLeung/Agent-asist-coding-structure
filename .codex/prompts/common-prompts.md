# 通用场景提示词

## 需求澄清

```text
你需要我完成什么目标？请补充：
1) 目标/范围（in/out）
2) 现状与期望差异
3) 运行环境与约束（OS/语言/框架/依赖/权限）
4) 验收标准（可测试的输出）
```

## 解释代码

```text
请按以下结构解释这段代码：
1) 入口与输出
2) 核心数据结构与关键路径
3) 关键边界条件/异常分支
4) 复杂度与潜在风险
5) 可改进点（不改变行为的重构建议）
```

## 生成实现方案

```text
请给出实现方案，要求：
- 先给总体思路与模块拆分
- 再给关键接口定义/数据结构
- 再给实施步骤与验证方式
- 标注可能的风险点与回滚策略
```

## 输出变更摘要

```text
请生成变更摘要，包含：
- 修改了哪些文件（按模块归类）
- 行为变化点与影响范围
- 如何验证（命令/用例/步骤）
```
