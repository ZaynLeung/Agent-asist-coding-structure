# 03 强化学习

强化学习在机器人（尤其是灵巧手操作）中的应用与关键算法。

本目录按**范式（Paradigm）**分类，介绍灵巧手操作中常用的强化学习知识。每种范式下介绍主流算法，并附面试常见问题。

## 目录结构

- [index.md](index.md)：范式索引与导航
- [on-policy.md](on-policy.md)：On-Policy 范式
- [off-policy.md](off-policy.md)：Off-Policy 范式
- [offline-rl.md](offline-rl.md)：Offline RL
- [hierarchical-rl.md](hierarchical-rl.md)：Hierarchical RL
- [residual-rl.md](residual-rl.md)：Residual / Hybrid RL
