# Hierarchical RL

## 背景

将长视角任务分解为高层目标与低层技能，降低探索难度，适合灵巧手的多阶段操作任务。

## 主流算法

### Options Framework

- 定义可重用的子策略（options），高层选择启动哪个 option。

### Feudal Networks / HIRO

- 高层设定目标，低层尝试达到该目标，常用于分层控制。

### Skill Learning

- 通过自监督或演示学习可复用技能，再用高层策略组合。

## 面试常见问题

1. Hierarchical RL 如何解决长视角任务的稀疏回报问题？
2. Options 的终止条件如何设计？
3. 高层与低层的训练顺序有哪些常见策略？
4. 在灵巧手中，如何定义有效的子任务或技能？
