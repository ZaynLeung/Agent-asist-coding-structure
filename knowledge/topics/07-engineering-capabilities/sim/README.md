# Sim 仿真平台

记录与灵巧手、人形机器人、双臂平台相关的主流机器人仿真平台。

以下为当前常见平台的简要概述（按使用频率与相关性排序）。

## 主流平台

### NVIDIA Isaac Lab / Isaac Sim

- **主要用途**：GPU 并行大规模训练（整身控制、操作、灵巧操作）；高保真渲染与传感器仿真；与 NVIDIA 生态（GR00T 等）深度集成。
- **相关性**：对 Unitree H1/G1、Fourier GR1T2 等人形、Allegro / Shadow / Inspire 等灵巧手有原生支持；提供双臂与整身操作任务。
- **使用须知**：依赖 NVIDIA GPU；学习曲线较陡；资产与 USD 工作流需要适配。

### MuJoCo / MJX / MuJoCo Warp

- **主要用途**：高精度接触富集动力学仿真；学术研究与操作基准（如 LIBERO、RoboCasa）的默认选择。
- **相关性**：MuJoCo Menagerie 提供大量灵巧手与人形模型；MJX 支持 GPU 并行；常用于灵巧抓取与手内操作。
- **使用须知**：视觉渲染较弱，多与 Isaac Sim 等组合使用；开源且轻量。

### ManiSkill / SAPIEN

- **主要用途**：GPU 并行操作与视觉数据采集；多机器人形态与任务（包括灵巧操作、人形、移动操作）。
- **相关性**：对 Allegro Hand、Unitree 人形等有支持；提供大量操作任务与示范数据。
- **使用须知**：强调视觉与并行仿真速度；部分资产许可证需注意。

### Genesis

- **主要用途**：开源 GPU 原生仿真器，强调多物理（刚体、可变形、流体等）与高吞吐量人形仿真。
- **相关性**：适合需要更复杂接触或可变形体的操作研究。
- **使用须知**：较新项目，生态仍在快速发展中。

### 其他常见

- **Gazebo / Ignition**：ROS 生态集成强，适合部署前集成测试。
- **PyBullet / Drake**：轻量或控制理论取向。
- **Robosuite**：基于 MuJoCo 的操作基准框架。

## 选择建议（针对灵巧手 / 人形 / 双臂）

| 场景 | 推荐平台 |
|------|----------|
| 大规模 GPU 并行 RL 训练 | Isaac Lab |
| 接触精确与学术基准 | MuJoCo / MJX |
| 视觉数据与多任务操作 | ManiSkill |
| 可变形体 / 复杂物理 | Genesis |
